# Geode Checker

A macOS app inspired by the Geode modding ecosystem for Geometry Dash.

Geode Checker includes a Geode status checker, a collection of minigames, and a simulated mod-management interface.

## Features

- **Geode Status Checker** – Checks the Geode website for compatibility and update information.
- **Mod Simulator** – Explore a simulated mod-management interface.
- **Custom Mods** – Experiment with creating and managing simulated mods.
- **Minigames** – Includes Flappy Cube, Wave Dash, Memory Match and Reaction Test.
- **Settings** – Customise parts of the application.

## Download

1. Open the [Releases](../../releases) page.
2. Download the latest macOS ZIP file.
3. Extract the ZIP.
4. Move `Geode Checker.app` to your Applications folder.
5. Open the app.

**Note:** The app is currently ad-hoc signed and may trigger a macOS security warning.

## Important Information

Geode Checker is an independent project and is not affiliated with the Geode team, Geometry Dash or RobTop Games.

**This is a simulator.** Mod installation, downloading and other mod-management features are simulated. It does not actually install Geode mods or modify your Geometry Dash installation.
